A museum label from the year 3000 for a printed QR code — one line, at most 200 characters, written for make.fun's "Museum of the Year 3000" bounty.

> Printed QR code, c. 2024. Humans pointed their phones at this maze to order lunch. Many starved politely while it loaded.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` writes the label to `/output/entry.txt` (and prints it). The entry is a fixed, hand-written line, so every run produces the same 121-character text.
